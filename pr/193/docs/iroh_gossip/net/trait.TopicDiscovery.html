Expand description

Remembers the good peers of a topic, and discovers peers for it.

Gossip calls Self::discover for a topic that has no neighbors, and joins the topic through each peer the stream yields. The hooks tell the implementation which peers proved good: a peer that became our neighbor, and a peer we received a message from. They are synchronous and called on the gossip actor, so they must be cheap. An implementation that needs to do IO in them should spawn it.

A peer we lose because we ourselves went offline looks failed to us, so an implementation that remembers peers should not forget them on failure.

fn discover(&self, topic: TopicId) -> BoxStream<EndpointId>

Returns a stream of peers to join topic through, for example the results of a DHT lookup as they arrive.

Called for a topic without neighbors, at most every 10 seconds, and never while an earlier stream for the topic still runs. Gossip joins through each peer the stream yields, and drops the stream once the topic has a neighbor. The stream is polled on the gossip actor, so it must not block.

fn peer_seen(&self, _topic: TopicId, _peer: EndpointId)

We received a message in topic from peer, so it is reachable and in the topic.

Called for every message, from neighbors and other peers alike, so it must be very cheap. Use it to refresh a peer that stays a neighbor for a long time.
