62/// Publish and subscribe on gossiping topics.
63///
64/// Each topic is a separate broadcast tree with separate memberships.
65///
66/// A topic has to be joined before you can publish or subscribe on the topic.
67/// To join the swarm for a topic, you have to know the [`PublicKey`] of at least one peer that also joined the topic.
68///
69/// Messages published on the swarm will be delivered to all peers that joined the swarm for that
70/// topic. You will also be relaying (gossiping) messages published by other peers.
71///
72/// With the default settings, a node has up to 5 active neighbors per topic (the default active view).
73///
74/// Even though the [`Gossip`] is created from a [`Endpoint`], it does not accept connections
75/// itself. You should run an accept loop on the [`Endpoint`] yourself, check the ALPN protocol of incoming
76/// connections, and if the ALPN protocol equals [`GOSSIP_ALPN`], forward the connection to the
77/// gossip actor through [Self::handle_connection].
78///
79/// The gossip actor will, however, initiate new connections to other peers by itself.
80///
81/// Either side retires a connection after 10 seconds without a stream in either
82/// direction. Gossip opens a control stream on each connection, which
83/// is the only bidirectional stream it opens. Do not use a connection that you passed to
84/// [`Self::handle_connection`] for other traffic.
85///
86/// The actor stops when you drop the last clone of [`Gossip`]. Keep a clone for as long as you
87/// need the topics. Call [`Self::shutdown`] to leave the topics cleanly first.
88#[derive(Debug, Clone)]
89pub struct Gossip {
90    inner: Arc<Inner>,
91}
92
93/// A message from the [`Gossip`] handle to the actor.
94#[derive(Debug)]
95enum ToActor {
96    Join(Join),
97    Connection(Connection),
98    Shutdown { reply: oneshot::Sender<()> },
99}

101/// A request from [`Gossip::subscribe_with_opts`] to the actor to join a topic.
102#[derive(derive_more::Debug)]
103struct Join {

105    bootstrap: BTreeSet<EndpointId>,

109    /// The actor answers once it registered the topic and applied the join.
110    registered: oneshot::Sender<()>,
111}

134        if let Err(err) = self.shutdown().await {

200    /// Sets a filter that decides whether each received message is delivered and forwarded.
201    ///
202    /// The filter applies to all topics of this [`Gossip`]. It returns a [`Verdict`]:
203    /// [`Verdict::Accept`] delivers the message to the local subscribers and forwards it
204    /// to peers, as without a filter. [`Verdict::Reject`] does neither, so the message does
205    /// not spread beyond this node. Use it to drop messages that are invalid, obsolete, or
206    /// expired before they cost the swarm bandwidth.
207    ///
208    /// - The filter runs once per message id and topic, also if several peers send the
209    ///   message. A rejected message counts as seen for the
210    ///   [message id retention], so the filter does not run on a later copy. The node does
211    ///   not cache a rejected message, so a peer that asks this node for it with a graft gets
212    ///   nothing.
213    /// - The node does not forward a message that a peer sent to its neighbors only. For
214    ///   such a message, the filter decides only the delivery. A later copy gets the first
215    ///   verdict.
216    /// - Messages that this node broadcasts do not pass the filter.
217    /// - The filter runs on the task of the gossip actor and delays all topics while it
218    ///   runs. Keep it short and do not block. Check the cheap things first. If it needs
219    ///   state, keep it behind a lock.
220    /// - A rejection is final for this node: it does not deliver or forward the message
221    ///   later, also if the filter would now accept it.
222    /// - A later copy gets the verdict of the first copy, also when another peer sends it.
223    ///   So base the verdict on the topic and the content only. A verdict that depends on
224    ///   [`FilterContext::delivered_from`] applies to the copies of other peers too.
225    ///
226    /// Gossip does not authenticate the message content. A filter that checks authorship has to
227    /// verify a signature in the content.
228    ///
229    /// # Example
230    ///
231    /// A filter that accepts only messages in version 1 of an application format:
232    ///
233    /// ```
234    /// use iroh_gossip::net::{Gossip, Verdict};
235    ///
236    /// /// The first byte of the content holds the version of the format.
237    /// const VERSION: u8 = 1;
238    ///
239    /// let builder = Gossip::builder().message_filter(|message| {
240    ///     // The verdict depends only on the content, so it holds for every copy.
241    ///     match message.content().first() {
242    ///         Some(&VERSION) => Verdict::Accept,
243    ///         _ => Verdict::Reject,
244    ///     }
245    /// });
246    /// # drop(builder);
247    /// ```
248    ///
249    /// [message id retention]: PlumtreeConfig::message_id_retention
250    pub fn message_filter(
251        mut self,
252        filter: impl Fn(FilterContext<'_>) -> Verdict + Send + Sync + 'static,
253    ) -> Self {
254        self.config.filter = Some(MessageFilter(Arc::new(filter)));
255        self
256    }
257
258    /// Sets a verifier for the auth tokens of peers.
259    ///
260    /// A peer sends its token for a topic in the header of each stream that it opens for
261    /// the topic, see [`JoinOptions::auth_token`]. The verifier gets an [`AuthContext`] with
262    /// the topic, the authenticated id of the peer and the token, if the peer sent one. It
263    /// runs once per stream, before the node reads a message from it. After it rejects a
264    /// stream, the connection stops each later stream of the topic without a call. It
265    /// returns a [`Verdict`]:
266    ///
267    /// - [`Verdict::Accept`] reads the stream.
268    /// - [`Verdict::Reject`] stops the stream and reads nothing from it. The node does not
269    ///   process or forward any message of the peer on this topic, not even a membership message.
270    ///   It drops the peer from the topic, so it stops sending to the peer too. The peer sees
271    ///   [`Event::Refused`] on its topic. It sends no message of the topic to us on this
272    ///   connection again. Other topics on the connection do not change.
273    ///
274    /// The verifier applies to all topics of this [`Gossip`], also to topics that this
275    /// node has not joined, so it can set a policy for each topic. Without a verifier,
276    /// the node accepts every stream.
277    ///
278    /// - A token is opaque to gossip. To bind a token to its owner, include the endpoint id
279    ///   in it and compare it with the id the verifier gets.
280    /// - The verifier runs on the task of the connection, not on the actor. A slow one
281    ///   delays only the streams of that connection. It still must not block a thread.
282    /// - A panic in the verifier stops the gossip actor.
283    /// - The node never forwards a token. Every member must be able to check the token of every
284    ///   other member.
285    ///
286    /// [`JoinOptions::auth_token`]: crate::api::JoinOptions::auth_token
287    /// [`Event::Refused`]: crate::api::Event::Refused
288    pub fn topic_auth(
289        mut self,
290        verify: impl Fn(AuthContext<'_>) -> Verdict + Send + Sync + 'static,
291    ) -> Self {
292        self.config.topic_auth = TopicAuth::new(verify);
293        self
294    }

296    /// Sets how long a connection stays open without any stream, before this node retires it.
297    ///
298    /// The time runs while no stream is open on the connection in either direction, and no
299    /// message waits to go out. A connection to a neighbor keeps its streams open, so it
300    /// does not retire. To retire, the node finishes its streams and sends `GOAWAY`. A
301    /// later message to the peer opens a new connection. Either side can retire a
302    /// connection, so the shorter time of the two nodes applies.
303    ///
304    /// The default is 10 seconds. A shorter time closes unused connections sooner. A
305    /// longer one saves dials to peers that the node uses now and then.
306    pub fn retire_after(mut self, after: std::time::Duration) -> Self {
307        self.config.retire_after = after;
308        self
309    }

311    /// Spawns a gossip actor, and returns its handle.
312    ///
313    /// This has to run inside a tokio runtime. The actor stops when you drop the last clone of
314    /// the returned [`Gossip`].
315    pub fn spawn(self, endpoint: Endpoint) -> Gossip {
316        let metrics = Arc::new(Metrics::default());
317        let address_lookup = GossipAddressLookup::default();
318
319        // `Endpoint::address_lookup` returns `Err` when the endpoint is closed.
320        // In that case, the gossip actor will close too very soon for other reasons,
321        // so it's fine if we only add our `GossipAddressLookup` for the non-closed
322        // case. The alternative would be to return a `Result` from `spawn`,
323        // but as long as this is the only direct error case, it seems unwarranted.
324        if let Ok(endpoint_addr_lookup) = endpoint.address_lookup().as_ref() {
325            endpoint_addr_lookup.add(address_lookup.clone());
326        }
327        let (actor, to_actor) = Actor::new(endpoint, self.config, metrics.clone(), address_lookup);
328        let me = actor.endpoint.id().fmt_short();
329        let max_message_size = actor.proto.max_message_size();
330
331        let actor_handle = task::spawn(actor.run().instrument(error_span!("gossip", %me)));
332
333        Gossip::new(
334            to_actor,
335            AbortOnDropHandle::new(actor_handle),
336            max_message_size,
337            metrics,
338        )
339    }

342/// Options of the send queue to each peer, for [`Builder::send_queue`].
343///
344/// Gossip keeps one send queue per peer, shared between all topics. The queue
345/// holds up to [`Self::size`] bytes of messages on their way to that peer.
346/// When the queue becomes full, new data and announcement messages to that peer
347/// will be dropped to not hold up the whole swarm. If this peer cannot keep
348/// up with the volume of messages to be sent or relayed, the following
349/// may happen:
350///
351/// - A broadcast to the peer is dropped, and [`Metrics::msgs_dropped`] counts
352///   it. Gossip announces the broadcast to the peer again, and the peer
353///   fetches it while it is still cached, 30 s by default. A broadcast to
354///   direct neighbors is never repaired.
355/// - A control message to the peer closes the connection, and
356///   [`Metrics::peers_send_queue_full`] counts it. Both sides find new
357///   neighbors.
358///
359/// Independent of the size:
360///
361/// - Messages to a slow peer arrive late. The queue bounds bytes, not time,
362///   and QUIC buffers more on top.
363/// - A peer that takes no data for 60 s loses its connection, as does one
364///   that shares more topics with this node than its stream limit allows,
365///   100 by default.
366#[derive(Debug, Clone, Copy)]
367pub struct QueueOptions {
368    size: usize,
369}
370
371impl Default for QueueOptions {
372    fn default() -> Self {
373        Self {
374            size: queue::QUEUE_SIZE,
375        }
376    }
377}
378
379impl QueueOptions {
380    /// Sets the size of the queue in bytes, 1 MiB by default.
381    ///
382    /// A larger queue absorbs larger bursts and longer stalls without a
383    /// loss. It costs up to its size in memory for each peer, and it lets
384    /// more old data wait for a slow one. A message takes its encoded size
385    /// and about 130 bytes more. Whatever the setting, the queue is at
386    /// least 64 KiB, and fits eight messages of [`Builder::max_message_size`].
387    pub fn size(mut self, size: usize) -> Self {
388        self.size = size;
389        self
390    }
391}

421    /// Joins a gossip topic with options.
422    ///
423    /// Returns a [`GossipTopic`] once the node has registered the topic, so it accepts a join
424    /// from a peer from then on. It does not wait for a neighbor. To wait for the first
425    /// neighbor, await [`GossipTopic::joined`].
426    ///
427    /// See [`JoinOptions`] for available options.
428    ///
429    /// A broadcast reaches only the neighbors that exist when the node sends it. Await
430    /// [`GossipTopic::joined`] before the first broadcast. With no bootstrap peers, the node
431    /// waits until another node joins it.
432    ///
433    /// The node leaves the topic when you drop all handles of the topic.
434    ///
435    /// A [`JoinOptions::subscription_capacity`] of 0 counts as 1.
436    ///
437    /// # Errors
438    ///
439    /// - [`Error::TokenTooLarge`] if the auth token does not fit in a stream header.
440    /// - [`Error::Closed`] if the gossip actor stopped.
441    pub async fn subscribe_with_opts(
442        &self,
443        topic_id: TopicId,
444        opts: JoinOptions,
445    ) -> Result<GossipTopic, Error> {
446        if let Some(token) = &opts.auth_token {
447            if token.as_bytes().len() > self.inner.max_token {
448                return Err(e!(Error::TokenTooLarge {
449                    size: token.as_bytes().len(),
450                    max_token: self.inner.max_token
451                }));
452            }
453        }
454        let (commands_tx, commands_rx) = mpsc::channel(TOPIC_COMMANDS_CAP);
455        let (events_tx, events_rx) = mpsc::channel(opts.subscription_capacity.max(1));
456        let (registered_tx, registered_rx) = oneshot::channel();
457        self.inner
458            .to_actor
459            .send(ToActor::Join(Join {
460                topic_id,
461                bootstrap: opts.bootstrap,
462                auth_token: opts.auth_token,
463                events_tx,
464                commands_rx,
465                registered: registered_tx,
466            }))
467            .await
468            .map_err(|_| e!(Error::Closed))?;
469        registered_rx.await.map_err(|_| e!(Error::Closed))?;
470        Ok(GossipTopic::new(
471            commands_tx,
472            events_rx,
473            self.inner.max_content,
474        ))
475    }

477    /// Joins a gossip topic with the default options, and waits for the first neighbor.
478    ///
479    /// With an empty `bootstrap` list, or one that holds only our own id, the call waits until
480    /// a peer joins us. It has no timeout for that wait.
481    ///
482    /// # Errors
483    ///
484    /// - [`Error::JoinFailed`] if the join got no neighbor from its bootstrap peers, see
485    ///   [`GossipReceiver::joined`]. The call then drops the topic handle. Thus the node leaves
486    ///   the topic, unless another handle for the topic exists.
487    /// - [`Error::Closed`] if the gossip actor stopped.
488    ///
489    /// [`GossipReceiver::joined`]: crate::api::GossipReceiver::joined
490    pub async fn subscribe_and_join(
491        &self,
492        topic_id: TopicId,
493        bootstrap: Vec<EndpointId>,
494    ) -> Result<GossipTopic, Error> {
495        let mut sub = self
496            .subscribe_with_opts(topic_id, JoinOptions::with_bootstrap(bootstrap))
497            .await?;
498        sub.joined().await?;
499        Ok(sub)
500    }

504    /// It does not wait for a bootstrap peer. To wait for the first neighbor, use
505    /// [`GossipTopic::joined`] or [`Self::subscribe_and_join`].
506    ///
507    /// # Errors
508    ///
509    /// Returns [`Error::Closed`] if the gossip actor stopped.
510    pub async fn subscribe(
511        &self,
512        topic_id: TopicId,
513        bootstrap: Vec<EndpointId>,
514    ) -> Result<GossipTopic, Error> {
515        self.subscribe_with_opts(topic_id, JoinOptions::with_bootstrap(bootstrap))

529    /// Handles an incoming [`Connection`].
530    ///
531    /// The connection should be an accepted, server-side connection.
532    /// Make sure to check the ALPN protocol yourself before passing the connection.
533    ///
534    /// Gossip owns the connection from now on, and retires it once it is idle.
535    ///
536    /// # Errors
537    ///
538    /// Returns [`Error::Closed`] if the gossip actor stopped.
539    pub async fn handle_connection(&self, conn: Connection) -> Result<(), Error> {
540        self.inner
541            .to_actor
542            .send(ToActor::Connection(conn))
543            .await
544            .map_err(|_| e!(Error::Closed))?;
545        Ok(())
546    }

548    /// Shutdown the gossip instance.
549    ///
550    /// It leaves all topics and sends `Close` to the peers. Then it stops the actor, and
551    /// drops all state and connections. A gossip
552    /// instance that is shut down already, or shutting down, returns `Ok` too.
553    pub async fn shutdown(&self) -> Result<(), Error> {
554        let (reply, reply_rx) = oneshot::channel();
555        let shutdown = ToActor::Shutdown { reply };
556        // The actor is gone or about to go, which is what the caller asks for.
557        if self.inner.to_actor.send(shutdown).await.is_ok() {
558            reply_rx.await.ok();
559        }
560        Ok(())
561    }
